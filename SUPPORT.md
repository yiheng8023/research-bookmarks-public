# Support

Community support is best effort.

- Source additions and corrections: open the matching structured issue form.
- Taxonomy or placement questions: open a taxonomy issue with the canonical URL
  and the smallest reproducible classification example.
- Security or privacy concerns: follow [SECURITY.md](SECURITY.md); do not post
  private bookmarks, browser exports, account data, sessions, credentials, or
  private-repository evidence in a public issue.

Before opening an issue, run the documented verification commands when the
problem involves generated data or repository tooling. Sponsorship does not
create a response-time, review-priority, source-admission, or release promise.
