# Code of Conduct

## Expected conduct

Be respectful, evidence-oriented, and specific. Discuss sources, taxonomy, and
repository behavior without attacking people or communities. Respect privacy,
licensing, attribution, and the public/private data boundary.

## Unacceptable conduct

Harassment, discrimination, threats, doxxing, publishing private bookmark or
account data, knowingly submitting unsafe links, and repeated bad-faith
disruption are not acceptable.

## Enforcement

Report conduct concerns privately to the repository owner through an
appropriate private GitHub channel. Maintainers may edit, hide, lock, or remove
content and restrict participation when necessary to protect people, data, or
the project. Enforcement decisions should be proportional and documented
privately when sensitive information is involved.
