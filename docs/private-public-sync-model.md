# Private / Public Sync Model

This public repository and the private `research-bookmarks` repository are
independent authority surfaces with one-way, review-gated candidate transfer.

```text
research-bookmarks-public
  -> taxonomy, official sources, import/export contracts

research-bookmarks
  -> full bookmarks, private notes, non-official resources, preference data
```

Public-to-private reuse may consume taxonomy and official/canonical source
seeds, but it remains a private-repository admission decision.

Private-to-public sync must be a filtered promote workflow. Do not mirror `research-bookmarks` into this public-safe repository.
